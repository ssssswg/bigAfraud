# W底策略说明书（WBottomStrategy）

## 概述

基于经典**双底反转形态**的量化选股策略，通过识别 W 底形态、颈线突破确认、趋势反转验证和量价配合分析，寻找潜在买入机会。

## 核心流程

W底形态识别 → 颈线突破确认 → 趋势反转验证 → 量价配合分析 → 假W底过滤

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `pattern_days` | `40` | 形态识别回溯天数 |
| `low_window` | `5` | 底部低点窗口 |
| `min_gap` | `10` | 两底最小间隔 |
| `bottom_diff_threshold` | `0.03` | 两底价差阈值（3%） |
| `min_pattern_days` | `10` | 形态最小天数 |
| `neckline_break_ratio` | `1.01` | 颈线突破幅度（1%） |
| `volume_ma_period` | `5` | 量能均线周期 |
| `volume_expand_ratio` | `1.2` | 突破放量倍数 |
| `short_ma_period` | `10` | 短期均线 |
| `long_ma_period` | `30` | 长期均线 |
| `volume_shrink_ratio` | `0.8` | 回调缩量比例 |
| `support_days` | `3` | 支撑确认天数 |
| `support_ratio` | `0.02` | 支撑位回踩幅度 |
| `max_break_days` | `20` | 突破后最大确认天数 |

## 适用场景与风险

- **适用**：双底形态 + 颈线突破确认的底部反转机会。
- **风险**：W 底可能失败（假 W 底），已有假底过滤逻辑；结合量价配合提高确认度。
