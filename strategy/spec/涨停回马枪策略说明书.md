# 涨停回马枪策略说明书（LimitUpPullbackStrategy）

## 概述

识别"**涨停后回调再次启动**"的形态：个股涨停后经过缩量回调，再次获得支撑/突破阻力时发出二次启动信号。

## 核心逻辑

1. 近期（6 日内）出现过涨停（涨幅 ≥ 9.5%）
2. 涨停后进入回调：回调天数 1~9 日，回调幅度受限（不超过 15%）
3. 回调过程缩量（成交量 ≤ 前期 50%）
4. 回调后回踩支撑（支撑位 ≥ 涨停收盘 95%）或突破阻力（≥ 涨停收盘 105%）确认启动

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `limit_up_lookback_days` | `6` | 涨停回溯天数 |
| `limit_up_threshold` | `0.095` | 涨停判定阈值（9.5%） |
| `volume_ratio_threshold` | `2.2` | 涨停日量比下限 |
| `pullback_days_min` | `1` | 回调最小天数 |
| `pullback_days_max` | `9` | 回调最大天数 |
| `pullback_range_min` | `0.0` | 回调幅度下限 |
| `pullback_range_max` | `0.15` | 回调幅度上限 |
| `volume_shrinkage_ratio` | `0.5` | 回调缩量比例 |
| `support_ratio` | `0.95` | 支撑位相对涨停收盘比例 |
| `resistance_ratio` | `1.05` | 阻力位相对涨停收盘比例 |

## 适用场景与风险

- **适用**：涨停后缩量回调到位的二次启动机会。
- **风险**：回调可能演变为趋势反转；需缩量确认与支撑/阻力位过滤。
