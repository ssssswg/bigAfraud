# 超跌反弹策略说明书（OversoldReboundStrategy）

## 概述

超跌反弹策略识别深度超跌后、出现**动能背离与底部特征共振**的潜在反弹买点。核心逻辑：股票区间跌幅足够大（深度超跌）→ 出现 MACD 底背离（动能衰竭）→ 配合底部形态/九转/启明星任一特征 → 且反弹幅度尚未过高（捕捉刚启动的买点）。

## 选股逻辑

**组合条件：C1 AND C2a（MACD 底背离，必须） AND (C2b OR C2c OR C2d) AND C3**

| 条件 | 规则 | 默认参数 |
|------|------|---------|
| **C1 超跌深度**（必须） | 近 100 个交易日内，区间最高价→最低价下跌幅度 > 50% | `lookback_days=100`、`decline_threshold=0.50` |
| **C2a MACD 底背离**（必须） | 窗口内价格创新低，但 MACD 柱未同步创新低（动能背离） | `macd_divergence_days=20`、`macd_fast=12`、`macd_slow=26`、`macd_signal=9` |
| **C2b 底分型** | 近三根 K 线最低价居中（缠论简化底分型） | `enable_bottom_fractal=True`、`fractal_require_yang=True` |
| **C2c 低位九转** | 最新交易日完成买入 Countdown 第 9 根（复用 LowTD9Strategy 状态机） | `enable_low_td9=True` |
| **C2d 启明星** | 近三根 K 线呈"阴-小实体-阳"反转雏形（宽松版） | `enable_morning_star=True`、`morning_star_body_threshold=0.03` |
| **C3 反弹幅度受限**（必须） | 选股日收盘相对区间最低价涨幅 ≤ 30%（只捕捉底部刚启动） | `rebound_cap=0.30` |

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `lookback_days` | `100` | 超跌检查回溯交易日数 |
| `decline_threshold` | `0.50` | 区间最高→最低下跌幅度阈值 |
| `bottom_window` | `3` | 底部特征搜索窗口 |
| `macd_divergence_days` | `20` | MACD 底背离判断窗口 |
| `macd_fast` / `macd_slow` / `macd_signal` | `12` / `26` / `9` | MACD 快/慢/信号线 EMA 周期 |
| `enable_bottom_fractal` | `True` | 启用底分型特征 |
| `fractal_require_yang` | `True` | 底分型右侧是否要求阳线 |
| `enable_low_td9` | `True` | 启用低位九转特征 |
| `enable_morning_star` | `True` | 启用启明星形态特征 |
| `rebound_cap` | `0.30` | 选股日收盘相对区间最低价涨幅上限 |
| `require_selection_day_yang` | `True` | 选股日必须阳线且涨幅 > 0 |
| `selection_day_min_gain` | `0.01` | 选股日相对前一日收盘最小涨幅（1%） |
| `volume_surge_ratio` | `1.3` | 选股日量能 / 前 5 日均量倍数下限 |
| `volume_avg_days` | `5` | 量能比较的基准均量窗口 |

## 实现特点

- **复用 LowTD9Strategy**：低位九转特征直接复用低位九转策略的状态机（`from strategy.low_td9_strategy import LowTD9Strategy`）。
- **数据方向**：`df` 倒序，`index=0` 为最新交易日（与框架 execute_selection 入口规范化一致）。

## 适用场景与风险

- **适用**：个股深度下跌（跌幅 > 50%）后出现动能背离与底部特征，捕捉底部刚启动的超跌反弹。
- **风险**：超跌反弹可能只是下跌中继；MACD 底背离在单边下行中可能多次出现（背了又背），需结合趋势与止损控制风险。
