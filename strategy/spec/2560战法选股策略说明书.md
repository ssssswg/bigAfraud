# 2560战法选股策略说明书（Strategy2560Selection）

## 概述

根据**2560 战法**的买入信号规则进行选股。核心逻辑：股价向上突破关键均线 + 均量线金叉确认量能趋势。

## 选股规则

1. **股价突破 25 日均线**：股价向上突破 MA25（趋势转强信号）
2. **均量线金叉**：5 日均量线向上穿过 60 日均量线（量能趋势确认）

选股策略只发出选股信号，不考虑持仓、卖出、加仓等条件。

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `ma_period` | `25` | 股价突破均线周期 |
| `ma10_period` | `10` | 辅助均线周期 |
| `vol_ma_short` | `5` | 短期均量线周期 |
| `vol_ma_long` | `60` | 长期均量线周期 |
| `min_price_change` | `0.05` | 突破最小涨幅 |
| `min_volume_ratio` | `1.2` | 最小量比 |
| `strategy_weight` | `70` | 技术面评分权重 |

## 适用场景与风险

- **适用**：趋势启动初期，价格与量能双双转强的个股。
- **风险**：均线/均量金叉可能出现假突破，建议结合大盘环境与止损。
