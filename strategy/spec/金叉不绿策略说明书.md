# 金叉不绿策略说明书（GoldenCrossNotGreenStrategy）

## 概述

识别 **MACD 水上金叉且绿柱数量 ≤ 3 根**的买入信号，捕捉强势股回调后的启动机会。

## 选股条件

1. **MACD 金叉**：DIF 上穿 DEA
2. **水上金叉**：金叉发生在 0 轴上方（`dif_above_zero=True`、`dea_above_zero=True`）
3. **绿柱受控**：金叉后 MACD 绿柱数量不超过 3 根（`max_green_bars=3`）——绿色 K 线/动能柱数量受控，信号质量更高
4. **布林带扩张**：布林带扩张中（`bollinger_expanding=True`），趋势启动

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `macd_fast` | `12` | MACD 快线周期 |
| `macd_slow` | `26` | MACD 慢线周期 |
| `macd_signal` | `9` | MACD 信号线周期 |
| `max_green_bars` | `3` | 绿柱数量上限 |
| `dif_above_zero` | `True` | DIF 是否要求在零轴上方 |
| `dea_above_zero` | `True` | DEA 是否要求在零轴上方 |
| `bollinger_period` | `20` | 布林带周期 |
| `bollinger_std` | `2` | 布林带标准差倍数 |
| `bollinger_expanding` | `True` | 是否要求布林带扩张 |

## 适用场景与风险

- **适用**：强势股回调后，MACD 水上金叉 + 绿柱受控的精准启动机会。
- **风险**：条件较严，命中率低但信号质量高；金叉后需确认动能延续。
