# 金三角策略说明书（GoldenTriangleStrategy）

## 概述

识别均线**金叉三角形**形态，A/B/C 三点金叉汇聚形成三角形，捕捉趋势启动/拐点信号。

## 形态定义

| 点位 | 定义 |
|------|------|
| **A 点** | 5 日均线上穿 10 日均线 |
| **B 点** | 5 日均线上穿 20 日均线 |
| **C 点** | 10 日均线上穿 20 日均线 |
| 三角形 | A、B、C 三点形成三角形 |

## 特殊形态

- **金蜘蛛**：A、B、C 三点汇聚于同一天（`ac_interval=0`），信号最强。

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `short_period` | `5` | 短期均线（A 点） |
| `mid_period` | `10` | 中期均线（B 点） |
| `long_period` | `20` | 长期均线（C 点） |
| `super_long_period` | `60` | 超长期均线（趋势过滤） |
| `ac_interval` | `3` | A 与 C 点最大间隔（0=金蜘蛛） |
| `c_cross_min_gain` | `0.01` | C 点金叉最小涨幅 |
| `c_cross_min_volume_ratio` | `1.1` | C 点金叉最小量比 |
| `lookback_days` | `30` | 形态识别回溯天数 |
| `strategy_weight` | `50` | 技术面评分权重 |

## 适用场景与风险

- **适用**：均线金叉三角（含金蜘蛛）的趋势拐点/启动信号。
- **风险**：三角形形成后可能回踩均线，需 C 点金叉量价确认。
