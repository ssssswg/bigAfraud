# 多方炮策略说明书（MultiPartyCannonStrategy）

## 概述

识别"**两阳夹一阴**"的 K 线组合形态，该形态代表多方短暂回调后再次发力，预示短线继续上攻。

## 指标定义（三根 K 线）

| 位置 | 要求 | 默认参数 |
|------|------|---------|
| 第一根（Day-2） | 中/大阳线：收盘>开盘、涨幅 ≥ 3% | `first_candle_rise=0.03` |
| 第二根（Day-1） | 小阴线/十字星：收盘<开盘、实体 ≤ 第一根阳线 50%、回调 ≤ 第一根涨幅 50% | `second_candle_body_ratio=0.5`、`second_candle_fallback_ratio=0.5` |
| 第三根（Day-0） | 阳线：收盘>开盘、收盘 > 第一根收盘价（突破确认）、涨幅 ≥ 3% | `third_candle_rise=0.03`、`third_candle_breakthrough=True` |

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `first_candle_rise` | `0.03` | 第一根阳线最小涨幅 |
| `second_candle_body_ratio` | `0.5` | 第二根阴线实体相对第一根比例上限 |
| `second_candle_fallback_ratio` | `0.5` | 第二根回调相对第一根涨幅比例上限 |
| `third_candle_rise` | `0.03` | 第三根阳线最小涨幅 |
| `third_candle_breakthrough` | `True` | 第三根是否要求突破第一根收盘价 |
| `second_volume_shrink_ratio` | `0.8` | 第二根缩量比例 |
| `third_volume_expand_ratio` | `1.0` | 第三根放量倍数 |
| `third_volume_ma_ratio` | `1.5` | 第三根相对均量倍数 |
| `volume_ma_period` | `5` | 量能均线周期 |
| `enable_ma_filter` | `True` | 是否启用均线过滤（MA20） |
| `ma_period` | `20` | 均线周期 |
| `enable_macd_filter` | `False` | 是否启用 MACD 过滤 |
| `macd_above_zero` | `True` | MACD 零轴上方要求 |
| `enable_kdj_filter` | `False` | 是否启用 KDJ 过滤 |
| `kdj_j_max` | `80` | KDJ-J 值上限 |
| `lookback_days` | `3` | 形态识别回溯天数 |

## 适用场景与风险

- **适用**：短线强势股回调后的再次发力。
- **风险**：形态失败率高，第三根若不放量突破易成假多方炮。
