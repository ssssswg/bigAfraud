# 趋势共振反转策略说明书（TrendResonanceReversalStrategy）

> 本策略为 **bigApush 独有策略**（KHunter 仅有参数配置残留、无实现类），由 bigApush 独立实现。

## 概述

通过 **RSI、均线、MACD 多指标共振**识别底部反转信号，捕捉下跌动能衰竭后由超卖转强的启动机会。

## 指标定义

| # | 指标 | 信号 |
|---|------|------|
| 1 | **RSI 突破** | RSI(14) 从超卖区域（30 以下）突破至中性区域（50 以上），表示从超卖转中性偏强 |
| 2 | **均线金叉** | 5 日均线向上穿越 20 日均线，表示短期趋势转强 |
| 3 | **MACD 金叉** | DIF 线上穿 DEA 线，表示动能转强 |

## 选股条件（全部满足）

- RSI 从 30 以下突破至 50 以上
- 5 日均线上穿 20 日均线
- DIF 线上穿 DEA 线
- 三个信号在 3 个交易日内发生（时间共振）

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `rsi_period` | `14` | RSI 周期 |
| `rsi_oversold` | `30` | RSI 超卖阈值 |
| `rsi_breakout` | `50` | RSI 突破阈值 |
| `short_ma_period` | `5` | 短期均线 |
| `long_ma_period` | `20` | 长期均线 |
| `macd_fast` / `macd_slow` / `macd_signal` | `12/26/9` | MACD 参数 |
| `signal_days` | `3` | 三信号共振时间窗口 |
| `lookback_days` | `5` | 回溯确认天数 |

## 适用场景与风险

- **适用**：超卖后多指标共振的底部反转机会。
- **风险**：共振信号强调"时间共振"（3 日内），需确认信号强度与量能配合。
