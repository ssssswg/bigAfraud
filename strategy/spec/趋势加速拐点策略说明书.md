# 趋势加速拐点策略说明书（TrendAccelerationInflectionStrategy）

## 概述

识别股票在**上升趋势中出现加速的拐点**，通过上升趋势、放量长阳、起涨位置、回调支撑四条件确认加速启动信号。

## 选股条件（四个条件都必须满足）

| # | 条件 | 说明 | 默认参数 |
|---|------|------|---------|
| 1 | **上升趋势** | 近 20 交易日用线性回归判断：斜率 > 0、p 值 < 0.05（趋势显著）、R² > 0.3（拟合良好） | `uptrend_lookback_days=20`、`uptrend_slope_threshold=0`、`uptrend_pvalue_threshold=0.01`、`uptrend_rsquared_threshold=0.5` |
| 2 | **放量长阳** | 近 10 个交易日出现涨幅 > 8%、成交量 ≥ 2 倍 5 日均量 | `price_increase_threshold=0.08`、`volume_ratio_threshold=2.0`、`volume_ma_period=5`、`surge_lookback_days=5` |
| 3 | **起涨位置低** | 长阳起涨点距最近最低点涨幅 < 15%（最长回溯 40 交易日） | `distance_threshold=0.15`、`lowest_point_lookback_days=40` |
| 4 | **回调不破** | 长阳线后回调未跌破长阳线开盘价 | — |

## 策略特点

- 顺势而为：在上升趋势中选股
- 信号明确：放量长阳是加速信号
- 多重确认：四个条件组合确认
- 风险可控：回调支撑明确

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `uptrend_lookback_days` | `20` | 上升趋势判断回溯天数 |
| `uptrend_slope_threshold` | `0` | 线性回归斜率阈值 |
| `uptrend_pvalue_threshold` | `0.01` | 趋势显著性 p 值阈值 |
| `uptrend_rsquared_threshold` | `0.5` | 拟合度 R² 阈值 |
| `price_increase_threshold` | `0.08` | 长阳涨幅阈值（8%） |
| `volume_ratio_threshold` | `2.0` | 长阳放量倍数 |
| `volume_ma_period` | `5` | 量能均线周期 |
| `surge_lookback_days` | `5` | 长阳搜索回溯天数 |
| `distance_threshold` | `0.15` | 起涨位置距离阈值 |
| `lowest_point_lookback_days` | `40` | 最低点回溯天数 |
| `min_data_length` | `50` | 最小数据长度 |

## 适用场景与风险

- **适用**：上升趋势中的加速拐点，趋势加速确认。
- **风险**：加速拐点可能出现在阶段高位；回调不破长阳开盘价是主要支撑依据。
