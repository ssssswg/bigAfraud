# 趋势起点策略说明书（TrendStartStrategy）

## 概述

识别趋势启动初期信号：**MACD 0 轴上方金叉 + 布林带上穿中轨**，配合阳线、站上 5 日线、放量确认，捕捉趋势启动机会。

## 策略逻辑（今天同时满足）

1. **MACD 金叉在 0 轴上方**：DIF > 0 且 DIF 从下往上穿越 DEA
2. **布林带上穿中轨**：收盘价从下往上穿越 BOLL 中轨
3. **当日阳线**：收盘价 > 开盘价
4. **站上 5 日线**：收盘价 > MA5
5. **成交量放大**：今日成交量 > 1.2 倍 5 日均量

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `macd_fast` | `12` | MACD 快线 EMA 周期 |
| `macd_slow` | `26` | MACD 慢线 EMA 周期 |
| `macd_signal` | `9` | MACD 信号线周期 |
| `boll_period` | `20` | 布林带周期 |
| `boll_multiplier` | `2` | 布林带标准差倍数 |
| `ma5_period` | `5` | 5 日均线周期 |
| `volume_ratio` | `1.2` | 成交量放大倍数 |

## 适用场景与风险

- **适用**：趋势启动初期，MACD 与布林带共振转强的个股。
- **风险**：启动初期信号可能有反复，需放量与站上均线确认。
