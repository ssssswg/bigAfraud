# 主升低吸策略说明书（MainUptrendDipBuyStrategy）

## 概述

主升低吸策略识别"**一拉 → 二调 → 长阳贴紧突破回调中最近反弹高点 R**"的结构性买点，在个股主升途中回调结束后、放量长阳突破关键位置时发出信号。**选股日 = 突破日**，当日判定，不含回踩/回看环节。

## 结构定义（五要素，全部满足才出信号）

| 要素 | 规则 | 默认参数 |
|------|------|---------|
| **C1 一拉** | 近 60 日内对 swing high 按高度由高到低扫描，取第一个涨幅 ∈ [30%, 100%] 的高点作为 H（L = H 前 45 日最低价）；涨幅不达标的高点跳过 | `rally_min_pct=30`、`rally_max_pct=100`、`recent_days=60`、`rally_low_lookback=45` |
| **C2 二调** | H 后最低价 P 的回撤 ∈ [18%, 一拉涨幅−8%)；且 P > L（一拉不得被全额回吐） | `pullback_min_pct=18`、`pullback_gap_pct=8`、`require_p_above_l=True` |
| **C3 定义 R** | H 之后、今日之前的最后一个 swing high（R < H；允许 R 早于 P） | `swing_window=2` |
| **C4 突破** | 今日阳线实体 ≥ 5%；收盘 > R 且突破幅度 ≤ 2%；量比 ≥ 1.8 | `min_body_pct=5`、`breakout_max_pct=2`、`volume_ratio=1.8` |
| **C5 均线** | 今日收盘 > MA5（含今日收盘） | `require_close_above_ma=True`、`ma_period=5` |

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `rally_min_pct` | `30.0` | 一拉涨幅下限（%） |
| `rally_max_pct` | `100.0` | 一拉涨幅上限（%）；0 = 不限制 |
| `rally_low_lookback` | `45` | L 取值窗口：H 前多少个交易日内取最低价 |
| `recent_days` | `60` | "近期"定义：H 只在该窗口内寻找 |
| `pullback_min_pct` | `18.0` | 二调回撤下限（%） |
| `pullback_gap_pct` | `8.0` | 二调回撤动态上限 = 一拉涨幅 − 该值（%） |
| `require_p_above_l` | `True` | 二调低点 P 必须高于起始低点 L |
| `swing_window` | `2` | swing high：前后各 N 根最高价均更低 |
| `min_body_pct` | `5.0` | 突破日阳线实体下限（%） |
| `breakout_max_pct` | `2.0` | 突破 R 的幅度上限（%）；核心参数 |
| `volume_ratio` | `1.8` | 量比下限 |
| `volume_ma_period` | `5` | 量比均量周期（不含今日） |
| `require_close_above_ma` | `True` | 是否要求收盘站上均线 |
| `ma_period` | `5` | 均线周期 |
| `min_data_len` | `106` | 最小 K 线长度（= recent_days + rally_low_lookback + 1） |

## 实现特点

- **无未来函数**：swing high 的右侧 `swing_window` 根 K 线必须已出现，信号日收盘后即可判定。
- **不做冷却去重**：同一结构在相邻交易日可连续触发（如需去重由引擎/运行器在信号层处理）。
- **数据方向**：内部统一转为正序（最旧在前）处理，不依赖调用方传入顺序。

## 适用场景与风险

- **适用**：个股已走出主升浪（一拉涨幅可观）、回调不破起点后再次放量启动的低吸机会。
- **风险**：突破 R 后若量能不足或大盘转弱可能失败；突破幅度上限（2%）设限较严，命中率偏低但信号质量高。
