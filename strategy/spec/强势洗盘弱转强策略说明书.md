# 强势洗盘弱转强策略说明书（StrongWashWeakToStrongStrategy）

## 概述

识别股票在短期内经历"**放量上涨 → 洗盘回调 → 再次走强**"的形态，捕捉主力洗盘后二次启动的机会。

## 选股条件

| # | 条件 | 说明 | 默认参数 |
|---|------|------|---------|
| 1 | **放量大阳线** | 最近 5 个交易日内出现涨幅 ≥ 8% 的大阳线，成交量 ≥ 5 日均量 2 倍 | `big_candle_lookback_days=6`、`big_candle_threshold=0.08` |
| 2 | **放量阴线洗盘** | 大阳线次日出现阴线，成交量 ≥ 大阳线的 1.5 倍 | `wash_volume_ratio=1.5` |
| 3 | **反包阳线** | 洗盘后 3 个交易日内出现反包阳线，收盘 > 大阳线收盘 或 > 洗盘日开盘 | `reversal_days=3` |
| 4 | **持续强势** | 反包后至今日的收盘价都在大阳线上方 | — |

## 策略特点

- 量价配合：强调成交量配合，确保资金真实参与
- 形态确认：大阳线、阴线洗盘、反包阳线的形态组合确认主力意图
- 时间窗口：严格的时间窗口限制，确保形态有效性
- 趋势确认：反包后的持续强势确认趋势反转

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `big_candle_lookback_days` | `6` | 大阳线回溯天数 |
| `big_candle_threshold` | `0.08` | 大阳线涨幅阈值（8%） |
| `volume_ratio_threshold` | `1.5` | 大阳线放量倍数 |
| `wash_volume_ratio` | `1.2` | 洗盘日放量倍数 |
| `reversal_days` | `3` | 反包确认窗口 |
| `reversal_price_threshold` | `0.0` | 反包价格阈值 |

## 适用场景与风险

- **适用**：强势股洗盘后二次走强的机会。
- **风险**：洗盘可能演变为趋势走坏；反包确认与持续强势条件可降低误判。
