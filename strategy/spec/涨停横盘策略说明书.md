# 涨停横盘策略说明书（LimitUpSidewaysStrategy）

## 概述

识别"**涨停后横盘整理 + 突破信号**"的形态：个股涨停后进入横盘整理，配合 KDJ 金叉 / MACD 金叉与放量确认，捕捉横盘后的突破机会。

## 核心逻辑

1. 近期（10 日内）出现过涨停（涨幅 ≥ 9.5%）
2. 涨停后进入横盘整理：横盘 1~10 日，振幅受限（高点 ≤ +8%，低点 ≥ -5%）
3. 横盘过程缩量（≤ 前期 70%）
4. 突破信号：KDJ 金叉 和/或 MACD 金叉 + 放量（量比 ≥ 1.3）

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `limit_up_lookback_days` | `10` | 涨停回溯天数 |
| `limit_up_threshold` | `0.095` | 涨停判定阈值（9.5%） |
| `volume_ratio_threshold` | `1.8` | 涨停日量比下限 |
| `sideways_days_min` | `1` | 横盘最小天数 |
| `sideways_days_max` | `10` | 横盘最大天数 |
| `sideways_high_limit` | `0.08` | 横盘高点上限（+8%） |
| `sideways_low_limit` | `-0.05` | 横盘低点下限（-5%） |
| `volume_shrinkage_ratio` | `0.7` | 横盘缩量比例 |
| `support_drop_limit` | `-0.01` | 支撑回踩下限 |
| `kdj_n` / `kdj_m1` / `kdj_m2` | `9/3/3` | KDJ 参数 |
| `kdj_gold_cross_threshold` | `20` | KDJ 金叉阈值 |
| `macd_short` / `macd_long` / `macd_signal` | `12/26/9` | MACD 参数 |
| `volume_increase_ratio` | `1.3` | 突破放量倍数 |
| `strategy_weight` | `60` | 技术面评分权重 |

## 适用场景与风险

- **适用**：涨停横盘整理后的突破机会。
- **风险**：横盘可能向下变盘；需金叉与放量双重确认。
