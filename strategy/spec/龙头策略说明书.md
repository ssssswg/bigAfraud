# 龙头策略说明书（LeaderStrategy）

## 概述

龙头策略用于捕捉当日市场强势龙头股。核心思路：在当日涨停的个股中，进一步筛选出**早封板、高换手、小流通盘**的强势标的——这类股票往往是资金聚焦、次日溢价概率较高的龙头。

全部选股数据来自 tushare `limit_list_d` 接口，**按选股日实时批量获取**，单接口覆盖全部选股字段，本地不落库存储任何涨停数据。

## 选股条件（全部满足才入选）

| # | 条件 | 字段 | 默认口径 |
|---|------|------|---------|
| 1 | 当日涨停 | `limit_type='U'` | 数据层保证（已排除 ST/退市/炸板未封） |
| 2 | 封板时间早 | `last_time`（可配为 `first_time`） | 最后封板时间 < 11:00（110000） |
| 3 | 换手率适中 | `turnover_ratio` | 15% – 25%（无限售流通股口径） |
| 4 | 流通盘小 | `float_mv` | < 200 亿（20000000000 元） |
| 5 | 炸板次数 | `open_times` | 可选限制（默认不限） |
| 6 | 连板数 | `limit_times` | 可选下限/上限（默认不限） |

> 涨停判定由数据层保证（`limit_type='U'`），无需在 K 线内重算涨幅阈值。

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `seal_time_field` | `last_time` | 封板时间判定字段：最后封板 / 首次封板 |
| `seal_time_limit` | `110000` | 封板时间上限（HHMMSS，11:00） |
| `max_open_times` | `None` | 炸板次数上限；不限制 |
| `turnover_min` | `15.0` | 换手率下限（%） |
| `turnover_max` | `25.0` | 换手率上限（%） |
| `float_mv_max` | `20000000000` | 流通市值上限（元）= 200 亿 |
| `min_limit_times` | `1` | 连板下限；1 = 不过滤首板 |
| `max_limit_times` | `None` | 连板上限；不限制 |
| `limit_type` | `U` | 涨停类型 |
| `strategy_weight` | `70` | 技术面评分权重 |

## 数据源依赖

- 依赖 tushare `limit_list_d` 接口，需在 `config/tushare_config.json` 配置 token 且账号具备 **5000 积分**。
- 涨停取数模块：`scripts/collect_limit_up_pool.py`（按路径动态加载）。
- 未配置 token 时：策略优雅降级，不报错，实时涨停池为空（不出信号）。

## 实现特点

- 按交易日实时批量获取涨停池，**同一交易日只请求一次**（实例内缓存），全市场逐只选股不重复请求接口。
- 涨停数据仅内存参与选股，**不落库**。
- 框架为"逐只传入 K 线"（BaseStrategy.execute_selection），本策略以 (code, trade_date) 命中当日涨停股。

## 适用场景与风险

- **适用**：市场情绪活跃、涨停家数较多时的强势龙头博弈。
- **风险**：早封板+高换手的龙头可能已处于情绪高潮，追涨有回落风险；需结合仓位管理与止损。
