# 低位九转策略说明书（LowTD9Strategy）

## 概述

低位九转策略基于 Tom DeMark 的 **TD Sequential（TD 序列 / 9 转序列）**，识别"买入 Countdown（低位 9 转）**今日完成**"的个股，捕捉下跌动能衰竭的潜在底部买点。

## 核心规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | **买入 Setup 前置** | 连续 9 根 `close[t] < close[t-4]` 完成后，才启动买入 Countdown |
| 2 | **买入 Countdown** | 自 Setup 完成后，连续满足 `close[t] <= close[t-2]` 累计达到第 9 根，且**仅当今日（T日）为该连续序列第 9 根时入选**（"今天形成"低位 9 转） |
| 3 | **低位环境过滤** | 距阶段高点回撤 ≥ 阈值 且 收盘 < MA60 且 近 20 日涨幅 < 上限（默认关闭三项判定） |
| 4 | **取消规则** | Countdown 累计过程中若出现卖出 Setup 完成（连续 9 根 `close[t] > close[t-4]`），当前买入 Countdown 作废清零 |
| 5 | **完美信号（硬门槛）** | Countdown 第 8 或第 9 根最低价 < 第 6、7 根最低价，否则不入选 |

- 状态实时计算，不落库；复用 BaseStrategy 通用过滤（ST/退市/停牌）。
- 基准价统一使用收盘价（与评分/回测一致）。

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `setup_window` | `9` | 买入/卖出 Setup 所需连续根数 |
| `setup_offset` | `4` | 比较偏移 `close[t]` vs `close[t-4]` |
| `countdown_target` | `9` | Countdown 完成目标根数 |
| `countdown_offset` | `2` | 比较偏移 `close[t]` vs `close[t-2]` |
| `enable_low_filter` | `False` | 是否启用低位环境过滤（已按需求关闭） |
| `low_drawdown_window` | `60` | 回撤计算回溯交易日 |
| `low_drawdown_max` | `0.85` | 距阶段高点最大比例（≤则低位） |
| `enable_ma60` | `True` | 是否要求收盘价 < 60 日均线 |
| `max_upwave` | `0.30` | 近 20 日最大涨幅上限 |
| `enable_cancellation` | `True` | 卖出 Setup 完成则作废当前买入 Countdown |
| `enable_perfection` | `True` | 是否要求完美信号（第 8/9 根低点 < 第 6/7 根低点） |
| `min_data_len` | `13` | 最少历史交易日 |

## 适用场景与风险

- **适用**：个股经历长期下跌后，出现 TD 序列低位 9 转的潜在底部反转。
- **风险**：TD 序列为统计规律，不保证反转；低位 9 转后仍可能继续阴跌，需配合止损与仓位控制。
- **被复用**：作为超跌反弹策略（OversoldReboundStrategy）的底部特征之一。
