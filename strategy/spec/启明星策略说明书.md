# 启明星策略说明书（MorningStarStrategy）

## 概述

识别"**三根 K 线底部反转形态**"——启明星（晨星），下跌趋势末端出现止跌反转的经典底部信号。

## 指标定义（三根 K 线）

| 位置 | 要求 | 默认参数 |
|------|------|---------|
| 第一根 | 长阴线：收盘<开盘、实体 > 3%（下跌趋势） | `first_body_threshold=0.03` |
| 第二根 | 小实体 K 线：开收盘接近（阳/阴均可，实体很小），市场犹豫 | `small_body_ratio=0.3` |
| 第三根 | 长阳线：收盘>开盘、实体 > 阈值、突破 5 日均线（反转上升） | `long_candle_ratio=0.5` |

## 选股条件

- 三根 K 线按顺序出现（阴 → 小实体 → 长阳）
- 第三根长阳突破 5 日均线确认反转

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `lookback_days` | `3` | 形态识别回溯天数 |
| `small_body_ratio` | `0.3` | 第二根小实体相对阈值 |
| `long_candle_ratio` | `0.5` | 长阳实体相对阈值 |
| `volume_ratio` | `1.5` | 放量确认倍数 |
| `first_body_threshold` | `0.03` | 第一根长阴实体最小比例 |

## 适用场景与风险

- **适用**：下跌末端的底部反转信号。
- **风险**：启明星为单形态信号，建议结合均线/量能与大盘环境确认。
